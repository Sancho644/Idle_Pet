# Открытые вопросы

Вопросы из [GDD v1.2](design/GDD.md), раздел 20, и технические задачи. Предложенные численные значения требуют согласования.

| ID | Вопрос | Предложение / статус |
|---|---|---|
| O-01 | Точные причины и сроки смерти, старость | Утвердить пороги, длительности, возраст; смерть сохраняется |
| O-02 | Детализация офлайн-симуляции | Без лимита, специального замедления или защитного окна; смерть вне игры разрешена. Уточнить расход ресурсов, автономные действия, уведомления и обработку системных часов |
| O-03 | Длина суток, сон, возраст и темп жизненного цикла | Два независимых времени; 60 мин на сутки для первого теста |
| O-04 | Наследование имущества и валюты | Сохранять весь дом и коллекцию между поколениями |
| O-05 | Число видов, стадий, эволюций, редкость | Предварительно два базовых вида, по две взрослые формы на вид, четыре всего. Числа открыты. Редкость необязательна |
| O-06 | Формулы ухода, эволюции и бонусов | Конфигурируемые правила, тестирование истории |
| O-07 | Структура комнат и сетки | 0,5 м, 90°, одна активная комната, отдельные раскладки |
| O-08 | Автономный уход и расходники | Еду даёт игрок; остальное по правилам предметов |
| O-09 | Монетизация | Бесплатно на обеих платформах. Покупки за игровую валюту — предложение для MVP. Реальные платежи за пределами MVP, варианты монетизации открыты |
| O-10 | UI и ориентация Android | Проверить портретную и альбомную компоновку |
| O-11 | Возрастная аудитория, настройки, уведомления | Определить перед выпуском |
| O-12 | Название и визуальная идентичность | Рабочее название не финальное |
| O-13 | Баланс освещения, сна и особенностей | Согласовать формулу качества сна, пороги яркости и пригодности светильников, коэффициенты сна и восстановления энергии, вероятности получения особенностей |


## Технические вопросы

- Первый игровой прототип: проверить запуск APK на физическом Android-устройстве и визуально проверить Windows Player. [Backlog проверок](backlog.md).
- T04: проверить планирование и активацию Windows Toast в неупакованной Steam-сборке. Уведомления требуют отдельного утверждения.
- Согласовать условия отображения и повтора игровой просьбы выключить свет. Прогноз просьб об освещении и доставка системных уведомлений остаются предложениями. [Освещение и сон](design/lighting-and-sleep.md), [уведомления](design/notifications.md).
- Время, RNG, сериализация, атомарное сохранение и миграции: детализация TDD.
- VContainer запланирован и отложен до появления Bootstrap по TD-003. При подключении проверить совместимость выбранной версии. Прочие дополнительные зависимости согласовывать отдельно.
- Навигация летающих существ, целевые Android-устройства и бюджеты производительности.
- Наследование имущества, офлайн-автономия и точные условия смерти — до реализации соответствующих правил.
