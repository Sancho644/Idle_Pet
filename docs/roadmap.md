# Roadmap

| Этап | Название | Результат |
|---|---|---|
| T00 | Project Setup | Принят. Окружение, Git LFS, asmdef, EditMode и обе пробные сборки. [Результаты](technical/setup.md) |
| DESIGN | Design Specification | Завершён и принят пользователем. GDD v1.3, TDD v0.2, SD-01–SD-15, TD-007–TD-017, баланс v0.1 и аудит. Устранены R-01–R-05, закрыты O-14–O-19 и O-29–O-31. |
| T01 | Domain & Simulation | Готов к началу, ожидает отдельного задания. Domain Foundation → Simulation Core → Forecast & Verification. Каждая из восьми подзадач запускается отдельным заданием. |
| T02 | Care & Lifecycle | Стадии, потребности и уход, ритм, сон, логический свет, здоровье, болезни, пищеварение, отходы и терминальная смерть. Минимальные логические ресурсы без 3D. |
| T03 | Persistence & Time Integrity | Атомарная запись, восстановление, миграции, полный офлайн-прогресс, состояние источников и гибридное время по согласованной политике. |
| T04 | Notifications | Прогноз и изоляция, отмена, дедупликация и тихие часы. Windows Toast spike, выбор и проверка платформенных адаптеров после отдельного согласования. |
| T05 | First Playable Prototype | Graybox, ввод, камера, UI, естественный свет и управление основным светом, игровой сигнал. Проверить запуск на физическом Android и визуально проверить Windows Player. |
| T06 | Furniture & Behaviour | Сетка, предметы, инвентарь, логическая доступность, управляемые светильники и лотки. Utility AI, привычки и работа с ресурсами. |
| T07 | Species & Evolution | Виды, эволюция, особенности анатомии, коллекция и альбом поколений. |
| T08 | Economy & Content | Экономика, мини-игра, UI, контент, арт и звук. Реальные платежи вне MVP. |
| T09 | MVP Release | Проверки на целевых платформах, производительность, завершение Balance Simulation Lab, валидация контента, итоговый баланс и выпуск. |

После приёмки DESIGN архитектурных блокеров T01.01a нет. Старт подзадачи ожидает отдельного задания. Цель этапов по T03 — проверенная симуляция без графики. [Backlog](backlog.md) · [Открытые вопросы](open-items.md)

Автоматизированные сценарии баланса начинаются с ядром. Полноценный инструмент Editor расширяется вместе с покрытием игровых систем. [Баланс v0.1](design/balance-v0.1.md)
