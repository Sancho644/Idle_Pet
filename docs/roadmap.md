# Roadmap

| Этап | Результат |
|---|---|
| T00 | Принят. Окружение, документация, Git LFS, asmdef, EditMode-тест и пробные сборки Windows и Android |
| T01 | Чистая доменная модель и симуляция |
| T02 | Уход и жизненный цикл. Логическое освещение, качество сна, просьба выключить свет и `FearOfDarkness` |
| T03 | Сохранения и полный офлайн-прогресс, включая состояние источников света и влияние освещения на сон |
| T04 | Исследование Windows Toast. Проектирование и реализация уведомлений после отдельного согласования |
| T05 | Первый игровой прототип. Graybox комнаты, ввод, камера, навигация, естественный свет по циклу суток, управление основным светом и отображение просьбы питомца. Запуск на физическом Android-устройстве и визуальная проверка Windows Player |
| T06 | Мебель, сетка, инвентарь и эффекты, включая управляемые ночники и светильники |
| T07 | Эволюция, характер, коллекция, адаптеры анатомии |
| T08 | Экономика, мини-игра, UI, арт и звук |
| T09 | Баланс, тесты, оптимизация и MVP |

T01 пока не начат. Цель этапов T00–T03 — проверенная симуляция без графики. Статус отложенных проверок ведётся в [backlog.md](backlog.md).

Освещение, сон и боязнь темноты входят в MVP по GD-011–GD-020. Прогнозирование просьб об освещении остаётся частью предложения по уведомлениям. [Освещение и сон](design/lighting-and-sleep.md), [уведомления](design/notifications.md).
