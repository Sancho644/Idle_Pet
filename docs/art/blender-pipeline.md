# Blender pipeline — предложение

Blender + Codex через MCP для производства моделей. Подключать после технического прототипа. Mixamo только для совместимых гуманоидов; четвероногие/летающие требуют собственного рига, слаймы — blend shapes или процедурных анимаций. Не требовать единого скелета. Экспорт FBX или другой согласованный формат, тест единиц масштаба, осей, pivot, материалов, коллизий, skinning и импорта анимаций. Хранить исходники отдельно от экспортов с понятными именами; тяжёлые бинарные файлы через LFS. Вести реестр происхождения и лицензий сторонних ассетов/анимаций. Проверять в Unity на одном тестовом персонаже каждого семейства перед массовым производством. Действия Eat/Sleep/Play/Move/React имеют общую семантику независимо от визуального адаптера.
