## Пользовательская приёмка T01.02 Simulation Core

Пользователь принял T01.02c после повторного независимого ревью. T01.02a–T01.02c завершены. Подтверждены расширенный неизменяемый `GameState`, планировщик событий, `AdvanceTo`, транзакционный rollback, числовые пороги, снимки всех шести RNG-потоков, минимальный терминальный статус и R-04.

В рамках TD-016 принят общий бюджет событий логической отметки. Первоначальный лимит 256 настраивается через `SimulationConfigSO`. Снимок сохраняет использованный бюджет при восстановлении. Тело самостоятельной команды не расходует бюджет событий. Приоритет `need.threshold = 0` применяется в текущем техническом срезе. Приоритеты будущих игровых систем определяются отдельно.

Сбой начальной инициализации возвращает `InitializationFailed`, `State = null` и `LogicalTime? Reached = null`. `AdvanceTo` валидирует вход независимо от направления цели.
