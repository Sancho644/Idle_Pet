## Освещение и сон

GD-011–GD-020 утверждены пользователем 25.11.2026. Подробности приведены в [дизайн-спецификации](design/lighting-and-sleep.md).

| ID | Решение | Статус |
|---|---|---|
| GD-011 | Игрок может включать и выключать основное освещение комнаты. | Утверждено |
| GD-012 | Когда существо хочет спать, оно сигнализирует о необходимости выключить основной свет. | Утверждено |
| GD-013 | Освещение влияет на качество сна и эффективность восстановления энергии. | Утверждено |
| GD-014 | Некоторые существа обладают индивидуальной особенностью `FearOfDarkness` — боязнью темноты. | Утверждено |
| GD-015 | Для комфортного сна существу с `FearOfDarkness` нужен включённый ночник или подходящий светильник. | Утверждено |
| GD-016 | Управляемые источники света относятся к функциональной мебели. | Утверждено |
| GD-017 | Состояние источников света сохраняется. | Утверждено |
| GD-018 | Освещение и качество сна учитываются при полной офлайн-симуляции. | Утверждено |
| GD-019 | Естественное освещение зависит от ускоренного цикла суток. | Утверждено |
| GD-020 | Механика освещения и боязни темноты входит в MVP. | Утверждено |

## Технические решения T00

TD-001–TD-006 утверждены пользователем 25.11.2026.

| ID | Решение |
|---|---|
| TD-001 | Использовать `IdlePet.*` для сборок и пространств имён проекта. |
| TD-002 | В T00 создать `IdlePet.Domain` с `noEngineReferences: true`, `IdlePet.Application` со ссылкой на Domain и Editor-only `IdlePet.Tests.EditMode` со ссылками на обе сборки. Добавлять остальные сборки по мере появления кода. Полный граф описан в TDD. |
| TD-003 | Передавать необходимые зависимости через конструктор. VContainer запланирован, установка отложена до появления Bootstrap. |
| TD-004 | Использовать Git LFS для `*.fbx`, `*.blend`, `*.psd`, `*.tga`, `*.wav`, `*.mp4`. Unity YAML, C# и `.meta` хранятся в обычном Git. Миграция истории не проводится. |
| TD-005 | Собрать `SampleScene` в `Builds/T00/` для Windows x64 Mono Development и Android ARM64 IL2CPP Development APK. При необходимости Android использует временный ID `com.sancho644.idlepet.dev`. Проверить запуск Windows Player и отдельно отметить доступность проверки запуска Android. Windows IL2CPP в T00 не устанавливается. |
| TD-006 | Зафиксировать версии окружения и актуальные пути, задокументировать архитектурные риски. Предварительный объём MVP — два базовых вида и по две взрослые формы на вид, четыре всего. Реальные платежи за пределами MVP. Уведомления остаются предложением, исследование Windows Toast запланировано на T04. GD-001–010 сохраняются. |
